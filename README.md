# SE_DAY4_Software-Project-Management
## 1. Why is timely delivery crucial in software project management, and how can project managers ensure that deadlines are met?
Timely Delivery is crucial is important in software project management because it prevents overspending budget, ensures business and client trust, it avoids resource wastage.

Project managers can ensure deadlines are met by using agile methodology as it is flexible, dividing the tasks into manageable sprints, setting clear milestones with well-defined objectives and monitoring progress using software like jira.
## 2. How does effective cost control contribute to the success of a software project? What strategies can be used to prevent budget overruns?
Cost control contributes to the success of a software project by ensuring the project is financially sustainable, ensuring the funds are adequately allocated to the high-priority features and maintaining investor's confidence in the project

Strategies employed to prevent budget overruns are obtaining accurate cost estimations using tools like COCOMO, regular monitoring of expenses and implementing agile methodology which allows adjusting resources dynamically.
## 3. Compare and contrast Agile and Waterfall methodologies. What are the main advantages and disadvantages of each?
Agile Methodology
Advantages
It is iterative and flexible 
It identifies and mitigates risks early 
Testing occurs throughout the whole development phase

Disadvantages
It requires high customer involvement which might be difficult to find due to other factors
It is difficult to estimate costs upfront

Waterfall Methodology 
Advantages
It has a clear structure and a well-documented process
It pairs well with well-defined projects

Disadvantages
Testing only occurs after the development phase
It is hard to incorporate changes to the project

## 4. In what types of projects might Agile be more beneficial than Waterfall, and vice versa? Can you provide examples of each?
Agile is best suited for projects that are dynamic in nature with evolving requirements. An example of this is a mobile app whereby the users give feedback to the users to further improve the application.
Waterfall is best suited for well-defined projects which do not have evolving requirements. An example of this is a pilot navigation software
## 5. What are some methods for ensuring quality assurance throughout a software project? Why is it important to maintain high standards?
Some methods used to ensure quality assurance are automated testing, peer reviews, continuous integration. 

Maintaning high standards is important as it maintains and even improves customer satisfaction, reduces post-release bug fixes and it improves long-term maintainability 
## 6. How does defining the project scope contribute to successful project planning? What is a Work Breakdown Structure (WBS), and why is it useful?
Defining the project scope is useful as it clearly defines what is included in the project and prevents scope creep which might lead to delays and cost overruns

Work Breakdown Structure is a hierarchical decomposition of tasks into smaller, manageable units. It is useful as it assists in resource allocation, scheduling and cost estimation
## 7. What are the benefits of developing a detailed project schedule, and how can Gantt charts assist in this process?
The benefits of developing a detailed project schedule are it assists in tracking progress, ensures efficient resource allocation and improves team coordination

Gantt charts assist by providing a visual representation of project timelines and track progress against deadlines
